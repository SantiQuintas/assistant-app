🖐️ Controlador Gestual para PC (Virtual Mouse)
Este proyecto es una interfaz de control natural (NUI) que permite manejar la computadora usando únicamente las manos y una cámara web, simulando una experiencia al estilo "holograma" o interfaz de ciencia ficción.

El objetivo principal del sistema es liberar al usuario de la necesidad de usar un mouse físico. Mediante visión artificial, el programa lee los movimientos de la mano en tiempo real y traduce gestos naturales en acciones directas sobre el sistema operativo.

✨ ¿Qué permite hacer?
Mover el cursor: Apuntando con el dedo para navegar por toda la pantalla.

Click y Drag & Drop: Juntando los dedos (pellizco) para interactuar con archivos y ventanas.

Scroll dinámico: Usando gestos específicos para desplazarse por páginas o documentos sin tocar la rueda del mouse.
